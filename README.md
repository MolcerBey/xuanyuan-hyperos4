# Xuanyuan HyperOS 4

Work in progress: source-package inspection and reproducible customization for Xiaomi 15 Ultra (xuanyuan).

No flashable custom ROM has been produced yet. Camera runtime testing is omitted at the owner's request; this is not a claim of camera compatibility.

Candidate base: OS4.0.0.18.XOACNXM (China, Android 17). Package identity, signature, partition layout and build resource requirements must be verified before producing a flash bundle.
